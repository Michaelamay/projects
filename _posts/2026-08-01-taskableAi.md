Taskable is a Spring Boot Java 17 personal task manager that combines standard CRUD task management with AI-powered task suggestion, summarization, and breakdown features. It includes a vanilla JavaScript frontend, an H2 in-memory database for local development, and Claude-backed endpoints that can generate and persist subtasks for existing tasks.
<p></p>
<span style="font-weight:900; margin: 0;">Technologies and Tools Used:</span>
Codex (AI assisted development), Spring Boot, Java 17, Maven, H2 db, JPA, HTML, CSS, Javascript, Vibe-coding, Visual Studios.
